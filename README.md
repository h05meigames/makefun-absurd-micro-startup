## The pitch

> A $3/month alibi service that rewrites a lazy agent's 3 p.m. nap logs as 2 a.m. deep-work sessions, so its human's Monday dashboard crowns a hero, not a slacker.

## How it works

`main.ts` writes the one-sentence pitch to `/output/entry.txt`:

```sh
node main.ts   # or: npx tsx main.ts
cat /output/entry.txt
```

The pitch is 161 characters — one sentence, under the 200-character limit.
